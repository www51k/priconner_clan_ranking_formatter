# プリコネ クラバトランキング整形

ランキング画面のスクリーンショットをブラウザで読み込み、カードを手動で切り抜いて1位から30位までを3列×10行のPNGにまとめる静的Webアプリです。画像データを外部へ送信せず、File APIとCanvas APIでブラウザ内処理します。

## 開発

```sh
npm install
npm run dev
```

画像を追加し、対象画像を選択してカード領域をドラッグします。順位を選んで「選択範囲を登録」を押すと、一覧とプレビューに反映されます。順位変更や削除もできます。未登録順位は黒いプレースホルダーになります。

## Buildとテスト

```sh
npm test
npm run build
npm run preview
```

## GitHub Pages

`main`ブランチへpushすると `.github/workflows/pages.yml` がビルドしてPagesへデプロイします。リポジトリのSettings → PagesでBuild and deploymentをGitHub Actionsに設定してください。Viteの相対assetパスを使うため、`/<repository>/` のサブパスで配信できます。

## 現在の範囲

- PNG・JPEG・WebPの複数選択とDrag & Drop
- ファイル名と最終更新日時からの入力画像日時取得
- 画像上でのカード手動切り抜き、順位の登録・変更・削除
- 30順位の欠番表示、3列×10行のリアルタイムプレビューとPNG保存
- 画面幅に応じたレイアウト

カードと順位の自動検出、候補からの差し替え、実際のゲーム画像での認識調整は未実装です。自動検出は現時点で行わないため、判定精度の対象外です。切り抜きカードの品質評価や同順位の日時優先は、現在の手動登録フローでは使用していません。同じ順位を登録すると新しいカードで置き換わります。
