# プリコネ クラバトランキング整形

ランキング画面のスクリーンショットをブラウザで読み込み、カードを自動で切り出して1位から30位までを3列×10行のPNGにまとめる静的Webアプリです。画像データを外部へ送信せず、File APIとCanvas APIでブラウザ内処理します。

## 開発

```sh
npm install
npm run dev
```

画像を1位から下へスクロールした順にまとめて追加すると、自動でカードを切り出して順位を割り当てます。重複して写ったカードは見た目を照合してまとめます。一覧では誤認識した順位の変更や不要カードの削除ができます。未登録順位は黒いプレースホルダーになります。

## Buildとテスト

```sh
npm test
npm run build
npm run preview
```

## GitHub Pages

`main`ブランチへpushすると `.github/workflows/pages.yml` がビルドしてPagesへデプロイします。リポジトリのSettings → PagesでBuild and deploymentをGitHub Actionsに設定してください。Viteの相対assetパスを使うため、`/<repository>/` のサブパスで配信できます。

## 現在の範囲

- PNG・JPEG・WebPの複数選択とDrag & Drop
- ファイル名と最終更新日時からの入力画像日時取得
- ランキングカードの自動切り抜きと連番割当
- 重複カードの画像特徴照合、順位の変更・削除
- 30順位の欠番表示、3列×10行のリアルタイムプレビューとPNG保存
- 画面幅に応じたレイアウト
- 画面下部にバージョン、コミット日時、コミットSHAを表示
- 公開成果物の`version.json`と照合し、現在表示している画面が公開中の最新版か判定

行検出は添付された全クランランキング画面の相対レイアウトに合わせています。順位番号自体はOCRせず、画像の並びとカードの重複照合から連番を割り当てます。そのため、1位から順に並んだ画像を選択してください。別のゲーム画面レイアウトや画面比率での認識調整は今後の対象です。

バージョン情報の確認は同じPagesサイト内の`version.json`を取得します。外部APIへのアクセスや画像の送信はありません。
