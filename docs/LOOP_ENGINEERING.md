# Loop Engineering — priconner_clan_ranking_formatter

対象: 順位画像の1〜30位連番、重複/欠番処理、画像日時認識
情報源: AGENTS.md、README.md、src/、tests/。例示タスクは現時点の未完了を保証しない。正本/未コミット差分を確認する。

## 開発ループ（1起動 = 1タスク）
1. **現状調査**：AGENTS.md、既存TODO/試験/直近の失敗、git statusを読む。完了・停止・担当不明を分ける。
2. **小タスク選択**：READY表示がなくても未完了から独立した1件を選ぶ。候補例: 順位連番・重複判定・欠番などの未検証境界1件。
3. **仮説**：再現条件・最小変更範囲・合格条件を記載。
4. **変更**：未コミットや原本を保全して許可済みワークツリーに最小差分。
5. **検証**：npm test ; npm run build。未実行の検証は未検証と区別。
6. **評価**：PASS / BLOCKED_INPUT / BLOCKED_ENV / TEST_INFRA_ERROR / TASK_FAIL を証拠から分類。
7. **次工程**：変更ファイル・テスト結果・ブロッカー・次に独立実行できるタスク1件を残す。

## 安全と継続
画像・クラン非公開情報の外部送信、確認前のPages公開をしない。同一失敗の根拠ない反復は禁止。新証拠がある場合も自動再試行は同じ失敗署名1回まで。一部のBLOCKEDを理由に全作業を止めない。ユーザー停止/権限不足/結果不明の副作用は再開せず保留。監視と進捗台帳だけでPASSにしない。OSスケジューラー登録は別工程で、ここでは行わない。

記録: task_id｜仮説｜変更ファイル｜テストコマンド/結果｜分類｜未検証範囲｜次タスク。
